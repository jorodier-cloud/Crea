# Consignes pour Claude Code sur ce repo

- Sois concis. Pas de récap de ce que tu vas faire, pas de plan détaillé à l'oral avant d'agir.
- Pas de liste d'étapes ni d'explication du raisonnement en texte — fais, puis résume en 1-2 phrases ce qui a changé.
- Ne pas attendre de confirmation avant d'agir sur les propositions faites : commit, push, ouverture de PR compris.
- Une confirmation reste nécessaire uniquement pour les actions destructrices ou irréversibles hors git (suppression de données, migration DB, secrets, force-push).
- Réponds en français, direct, sans formules de politesse.
